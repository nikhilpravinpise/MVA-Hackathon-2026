## The citation gate (`tools/verify_citations.py`)

- Detects `PMID:` (any separator), pubmed URLs, `DOI:`/`doi.org/`/bare
  `10.x/...` (mid-string parens preserved, trailing punctuation stripped),
  `PMCID:`/`PMCnnnnnn`/PMC-article URLs.
- Resolves via esummary (db=pubmed AND db=pmc, batched 200, sorted ids,
  <=3 req/s shared limiter) and Crossref `/works`. PMC retraction state is
  inherited from its linked PMID record.
- Retraction signals: PubMed `pubtype` in {Retracted Publication, Retracted
  and Republished Article, Withdrawn Publication}; Crossref
  `updated-by`/`update-to` type `retraction`; `RETRACTED:` title prefix.
  (The Wakefield DOI needed the updated-by/title signals - `update-to`
  alone misses it.)
- Expectation check: `{"PMID:x": {"title","year"}}` maps in JSON (L3's
  dossier `citations` blocks match this) -> normalized token Jaccard >=0.8
  + exact year. Verified live: all current dossier expectations pass.
- Coverage check: paragraphs/list-items/table-rows with a number+unit, %,
  or mechanism verbs must carry a citation or `[repo:...]` ref. Skips
  `agent_prompts/`, `agent_reports/`, and the intelligence docs
  (rules_refresh/landscape/form_map). Fatal only under `--coverage-strict`.
- Cache: `docs/track2/citation_cache.json` committed; `--refresh`
  re-pulls; `--offline` replays (uncached = fail); cache file excluded
  from its own scan; `--offline --refresh` rejected (exit 2).
- Output: human summary + `--json` machine report (`t2.citation_check/1`).
- Current live result: **70 citations, 0 unresolved, 0 retracted,
  0 mismatched, 0 uncovered - PASS** (`--offline` identical, 0 requests).
