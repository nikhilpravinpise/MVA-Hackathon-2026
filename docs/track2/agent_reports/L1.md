## Key findings (all from live API responses)

**Allele 1 - p.Leu737Ter = predicted NULL.**
- Exon 17/23 (ENSE00001029409). PTC first nucleotide sits **748 nt upstream
  of the last exon-exon junction** -> classic NMD substrate by the 50-55 nt
  rule (Nagy-Maquat PMID:9644970; Lindeboom rules PMID:27618451).
- If translated anyway: 736-aa fragment, 29.9% of protein lost including the
  entire kinase-like domain (766-1050), active site 882, PLK1 sites T792/T1008.
- gnomAD v4: exomes 115/1,461,846 (AF 7.9e-5); no homozygotes.
- ClinVar VCV000533901: **Pathogenic/Likely pathogenic** for MVA1
  (OMIM:257300), multiple submitters no conflicts.

**Allele 2 - p.Asn1002Lys = predicted HYPOMORPH (unstable pseudokinase
domain).**
- Exon 23/23 (last exon). Inside the kinase-like domain (766-1050), 6 aa
  from PLK1 phosphosite T1008.
- Scores: AlphaMissense **0.9229 likely_pathogenic**, SIFT 0.01 deleterious,
  PolyPhen 0.997 probably_damaging, CADD_phred 24.5, phyloP 5.115.
  REVEL 0.472 is *moderate* - stated honestly, not overclaimed.
- AlphaFold v6: pLDDT 91.06; 27 residues within 8 A (all-atom), contact
  number 54th percentile in domain -> partially packed surface site; the
  Asn->Lys charge swap plausibly destabilises packing.
- gnomAD v4: exomes **1/1,461,878**, absent from genomes.
- ClinVar: no record for c.3006T>G; same protein change via c.3006T>A is a
  single-submitter VUS (VCV004600147). Effectively novel allele.
- Suijkerbuijk 2010 (PMID:20516114): MVA missense alleles in/near the kinase
  domain are high-turnover unstable proteins -> N1002K predicted hypomorph
  via reduced abundance.

**Genotype:** canonical MVA1 null+hypomorph pattern (biallelic truncating
effectively unseen/lethal; all six UniProt-curated MVA1 missense variants
recorded "compound with nonsense mutation"; >50% BubR1 loss sufficient for
disease, PMID:16411201).

**Pathway:** BubR1 dosage -> weakened SAC + KARD/PP2A-B56 attachment
correction -> constitutional aneuploidy -> p53/p21 arrest + p16 senescence +
immune clearance -> growth failure/progeroid decline (mouse) + childhood
cancer predisposition (RMS Hanks 2004; Wilms Ochiai 2019 PMID:31081598;
adult GI Rio Frio 2010).

**Therapeutic signal handed to L2/L3:** residual-allele rescue is the most
mechanism-specific axis (SIRT2/NAD+ maintains BubR1, NMN raises it in vivo
PMID:24825348; K250 acetylation blocks BubR1 degradation PMID:19407811;
BubR1 overexpression corrects checkpoint+attachment and extends healthspan
PMID:23242215); senescent-cell clearance PMID:22048312; surveillance for
RMS/Wilms. Contraindicated: SAC/MPS1/KIF18A inhibitors (prophylactic),
p53 suppression, GH (precautionary - counter-evidence PMID:32738133
recorded), antimitotic aneugens.
