Build a deterministic, gene-agnostic mechanism-to-approved-drug engine:
1. config/track2.yaml (frozen, documented): seed genes with roles for this case (BUB1B disease gene; SAC/attachment partners BUB3, CDC20, MAD2L1, BUB1, TTK, AURKB, PPP2R5 family, KNL1; MVA genes CEP57, TRIP13, MAD1L1; senescence/aneuploidy-response genes CDKN2A, CDKN1A, TP53, MTOR, SIRT2, AMPK subunits...) - each with a one-line justification; scoring weights; approval criteria; benchmark cases + their known approved drug(s) declared BEFORE running (decision freeze).
2. src/track2 modules (stdlib urllib, with a cache layer that writes raw JSON responses to a cache dir and a replay mode for tests):
   - sources: Open Targets Platform GraphQL (https://api.platform.opentargets.org/api/v4/graphql: target -> drugs / known drugs, drug -> mechanisms/indications, max clinical phase - introspect the live schema, field names change), ChEMBL REST (mechanism, molecule max_phase, first_approval, black_box_warning, withdrawn), DGIdb v5 GraphQL (drug-gene interactions), STRING API (network for proximity), openFDA drug label API (pediatric_use, boxed_warning, indications) for approved-status and pediatric flags, SigCom LINCS (https://maayanlab.cloud/sigcom-lincs) signature search for reversal of an up/down gene set (implement the client; if the API is unreachable, degrade gracefully and record it).
   - approval filter: approved = ChEMBL max_phase == 4 and not withdrawn, cross-checked with openFDA label presence (record each evidence source); EMA-only noted.
   - network proximity (Guney et al. 2016 closest distance, z-score vs degree-matched random sets with a fixed seed) between drug targets and the disease module on STRING (score >= 700).
   - scoring: transparent weighted sum of normalized evidence channels + tiering (T1/T2/T3) with every contribution reported; axis assignment (A residual-BubR1 rescue, B senescence/damage, C aneuploid vulnerability/cancer interception) from a config target -> axis map.
