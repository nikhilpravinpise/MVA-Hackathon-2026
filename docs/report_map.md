# Report map - methods xlsx question -> report section (GATE-6 checklist)

Source: `hackathon-app/static/templates/methods_description_form.xlsx`
(sharedStrings + sheet1 order verified 2026-09-26). Track 1 carries 13
prompts; Q1 (the GenAI disclosure) is the only one marked "(required)" in
red. All are treated as de-facto required ("submissions without a methods
description may be judged less favorably").

| # | xlsx prompt (verbatim, abbreviated) | Report section |
|---|---|---|
| - | Team name | docs/team.md + report header |
| - | Model number (per submission) | report header `model{N}` |
| 1 | **(required) GenAI disclosure - provider, plan/tier, setting** | section 10 + docs/llm_log.md |
| 2 | Describe your model/approach in detail | sections 1 + 1a (pipeline + funnel table) |
| 3 | Automated output, or manual review/curation? | section 5 |
| 4 | Describe downstream manual review in detail | section 5 |
| 5 | Public-only data, or proprietary also used? | section 6 |
| 6 | Describe public data used in detail | section 6 |
| 7 | Describe proprietary data used | section 6 ("none") |
| 8 | Does the approach output compound-het pairs? | section 1 stage [4] + 0 (submission summary: pair in ONE row) |
| 9 | How were secondary/incidental findings handled? | section 7 |
| 10 | Estimate of run time and cost | section 9 + docs/runtime_log.md |
| 11 | Method abstract <=500 words, strengths+limitations | sections 12 + 13 |

## Gate

Every xlsx prompt maps to a section above; every number in the report is
regenerated by `python tools/make_report.py` from `results/` - regenerate
and diff before submission. A section that has not yet run says
"Pending dataset access" explicitly; a missing section is a gate failure.
