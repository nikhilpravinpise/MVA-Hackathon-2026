# Track 1 Methods Report - MVA Hackathon 2026 (model2: Exomiser arm)

**Team:** `nikhilpise` | **Model:** `model2` | **Companion report:**
`nikhilpise_track1_report.md` (the primary model1 write-up; this file
covers only what is distinct about model2 - the *standard-engine* arm of
our two-arm design).

## What model2 is

model2 is the output of **Exomiser 14.0.0** run in genome mode on the
challenge proband's VCF + the 8-term HPO set - the widely-used reference
implementation of phenotype-driven rare-disease prioritization (Jacobsen
et al./Monarch Initiative). It is the deliberately-boring half of our
design: an off-the-shelf engine run with its standard `2406` hg38 data
bundles, so that our custom funnel (model1) is checked against a tool the
field already trusts.

## Configuration

From `results/exomiser_patient/analysis.yml` (generated by
`tools/run_exomiser.py`):

* genomeAssembly `hg38`, analysisMode `PASS_ONLY`
* inheritance modes with MAF ceilings: AD 0.1%, AR hom-alt 0.1%, AR
  comp-het 2.0%, X-linked mirrors, MT 0.2%
* frequency sources: UK10K + gnomAD exome/genome subpopulations
* pathogenicity sources: REVEL, MVP, SpliceAI, AlphaMissense
* no candidate-gene list, no whitelist - unconstrained genome-wide run

## Why a second model entry

model1 is our custom deterministic funnel; model2 is the independent
engine agreeing with it. The two arms share no code and no ranking
logic; that both land the identical pair first is our strongest single
piece of evidence that the call is real rather than a funnel artifact
(model1 report, section 8a). Negative control: on an unrelated proband
VCF + HPO set the same configuration's top combined score is 0.0003
(nothing pathogenic surfaces) - documented in the model1 report's
control section.

## Limitations specific to this arm

* Standard engine, standard bundles - whatever Exomiser's `2406` data
  does not model (e.g. deep intronic splice, CNV/SV) stays invisible.
  The funnel's orthogonal arms (re-aligned reads, CNV screen, coverage)
  are what cover that ground; they are documented in the model1 report.
* epcr on the submitted row is Exomiser's own combined score - a
  sensible probability-shaped value, but not a calibrated diagnostic
  probability.
